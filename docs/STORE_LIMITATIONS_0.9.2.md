# Limitações da Loja 0.9.2

A Loja não promete identificar nominalmente cada keyshop em todas as respostas. A API pública do GG.deals usada pelo Ludex fornece preços agregados de `currentRetail` e `currentKeyshops` e uma URL para comparação detalhada. O Ludex não tenta descobrir o vendedor por scraping.

Quando a API do IsThereAnyDeal retorna uma oferta, o nome da loja oficial é exibido individualmente. Por isso a Nuuvem pode aparecer nominalmente quando houver oferta correspondente, enquanto Eneba/Instant Gaming podem aparecer apenas por meio do menor preço agregado de keyshops + link ao comparador.

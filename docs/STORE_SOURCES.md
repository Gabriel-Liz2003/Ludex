# Política de fontes da Loja

O comparador do Ludex usa somente fontes com acesso técnico sustentável. A aplicação não depende de scraping de páginas HTML de marketplaces.

- Steam: preço da própria Steam Store.
- IsThereAnyDeal: ofertas individuais de lojas oficiais/autorizadas e links de redirecionamento do próprio ITAD.
- GG.deals: menor preço de lojas oficiais e menor preço agregado de keyshops, mais link para a comparação detalhada.

Adapters diretos para novos revendedores só devem ser adicionados quando houver API pública/permitida ou acordo oficial adequado. Mudanças de HTML de terceiros não devem quebrar a Loja do Ludex.

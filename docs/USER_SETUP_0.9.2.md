# Configuração inicial da 0.9.2

Depois de atualizar:

1. Abra **Configurações → Conta Steam** e salve sua Steam Web API key para importar a biblioteca completa da conta.
2. Execute **Importar biblioteca completa**.
3. Para a Loja, abra **Configurações → Fontes da Loja**. Steam não exige chave; ITAD e GG.deals são opcionais e ampliam a comparação.
4. Rode **Atualizar** no provider Steam ou reinicie o Ludex para migrar fallbacks antigos de artwork e atualizar capas locais.
